Руководство пользователя

Меню «Файл»

  • Создать Ctrl+N — создает новый пустой документ.
  • Открыть Ctrl+O — открывает текстовый файл с диска.
  • Сохранить Ctrl+S — сохраняет текущие изменения в файл.
  • Сохранить как — сохраняет документ под новым именем.
  • Выход — закрывает приложение (предложит сохранить изменения).

Меню «Правка»

  • Отменить Ctrl+Z — отменяет последнее действие.
  • Повторить Ctrl+Y — возвращает отмененное действие.
  • Вырезать Ctrl+X — вырезает текст в буфер обмена.
  • Копировать Ctrl+C — копирует текст в буфер обмена.
  • Вставить Ctrl+V — вставляет текст из буфера.
  • Удалить Del — удаляет выделенный фрагмент.
  • Выделить все Ctrl+A — выделяет весь текст в редакторе.
